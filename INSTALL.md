# Installation Instructions

## Option 1: GitHub Pages (Recommended for CDN usage)

After pushing to GitHub, you can use the plugin via CDN:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/alin-morosanu/snowfall-plugin@main/snowfall-plugin.css">
<script src="https://cdn.jsdelivr.net/gh/alin-morosanu/snowfall-plugin@main/snowfall-plugin.js" data-auto-init defer></script>
```

## Option 2: Download Files

1. Download `snowfall-plugin.css` and `snowfall-plugin.js`
2. Add them to your project
3. Include in your HTML:

```html
<link rel="stylesheet" href="path/to/snowfall-plugin.css">
<script src="path/to/snowfall-plugin.js" data-auto-init></script>
```

## Option 3: Copy/Paste

Copy the contents of both files directly into your existing CSS and JS files.
