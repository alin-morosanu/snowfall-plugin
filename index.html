📚 Key Concepts

Container Type

container-type: inline-size;

Establishes a containment context for size queries on the inline axis (usually width).

Container Name

container-name: sidebar;

Assigns a name to the container for targeted queries.

@container Rule

@container (min-width: 400px) { }

Applies styles when container meets specified conditions.

Container Units

font-size: 5cqw;

cqw, cqh, cqi, cqb, cqmin, cqmax - units relative to container size.
